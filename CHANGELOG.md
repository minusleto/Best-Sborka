# История изменений

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Версии: `v0.МИНОР.ПАТЧ`.
Раздел `[Unreleased]` — то, что уже лежит в `main`, но ещё не выпущено тегом.
Пометка **⚠ Требует обновления у всех** означает, что хост и гости должны поставить одну и ту же версию (иначе вход на сервер невозможен).
Пометка **⚠ Ломающее** означает, что старые миры могут пострадать; такие изменения без крайней необходимости не делаем (см. [docs/WORKFLOW.md](docs/WORKFLOW.md)).

Как выпустить версию: перенесите содержимое `[Unreleased]` в новый раздел `## [0.1.0] - ГГГГ-ММ-ДД`, затем `git tag v0.1.0 && git push origin v0.1.0`.
GitHub Actions соберёт релиз и возьмёт описание из этого раздела.

## [Unreleased]

Первый выпуск ещё не сделан; ниже сводка того, что есть в `main` на 2026-10-30.

### Добавлено
- Машина **Assembler** (мод `bs-machines`): 6 входов, своя стоимость EU у каждого рецепта, окно в JEI (#24).
- Машина **Metal Former** (прокатка, экструзия, резка пластин в кабели) (#4).
- Блок **Build Core** и 7 уникальных компонентов для него; рецепт крафта черепа визера; рецепт сингулярности AE2 (#26).
- Мост рецептов IC2 ↔ AE2, **Vajra** по раскладке 1.12.2 (#26).
- Пластины (железо, медь, олово, бронза, золото, свинец, алюминий), оболочки-«item casing», Electric Motor, Forge Hammer, кусачки (#4, #13, #14).
- Материалы из IC2 Additions 1.12.2: оболочки, катушки, моторы, схемы, квантовое ядро.
- Квесты FTB: ванильная ветка (низкий/средний/высокий уровни), ветки IC2, исследование и финал «Легенда»; случайные таблицы наград.
- Русская локализация (#21): Naturalist, FTB Teams, ME Requester, AE Additions, Jade Addons, Iron Chests, UU-Matter, GeckoLib, Crafting Station JEI, MezzConfig, Xaero's World Map (всего около 900 строк).
- Инструменты процесса: `scripts/validate.py` (JSON/JS/защита реестра), `scripts/backup-world.*` (бэкап миров), проверка в GitHub Actions, workflow выпуска релиза.

### Изменено
- Схемы (hybrid/nano/quantum) делаются в Assembler, верстачные рецепты убраны (#27).
- Использование материалов Additions в рецептах AE2 (ME Controller, Quantum Ring требуют nano-оболочку), IC2 MFSU и EV-трансформатора (#23).
- Стекловолоконный кабель: рецепт 1.12.2 с любым стеклом.
- Ночное видение: рецепты очков восстановлены по 1.12.2, шлем использует Luminator.

### Исправлено
- AE2: в русской локализации «256k» было переведено как «16К» (6 строк), исправлено оверрайдом.
- Assembler: стоимость задаётся в EU за такт, а не суммой (машина не запускалась); рецепты с 1–6 входами загружаются корректно.
- Подсказки кабелей: строки больше не дублируются (#25).
