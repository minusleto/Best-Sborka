# Best-Sborka

**Статус:** разработка сборки Minecraft Forge 1.19.2.

Репозиторий предназначен для разработки и хранения изменений сборки. Когда сборка будет готова, отдельным этапом подготовим архив для скачивания.

## Что здесь хранится

- конфигурации модов, которые влияют на баланс и поведение сборки;
- скрипты KubeJS для рецептов, предметов и игровой логики;
- документация, список модов и история изменений.

## Среда

- Minecraft: 1.19.2
- Mod loader: Forge
- KubeJS: 1902.6.2 (из текущего экземпляра)
- Основные направления: IndustrialCraft 2 Classic, Applied Energistics 2, Gravisuit и дополнения.

## Как вносим изменения

1. Для каждой задачи определяем, где именно задаётся поведение: конфиг мода, datapack/JSON или KubeJS.
2. Меняем только нужные файлы и проверяем формат.
3. Фиксируем изменения отдельным коммитом с понятным сообщением.
4. Игровые миры, логи, пользовательские настройки и локальные данные не храним в репозитории.
