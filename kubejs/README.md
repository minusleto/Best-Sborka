# KubeJS — Best-Sborka

Здесь будут храниться **собственные** скрипты сборки. Скрипты из исходного экземпляра пока не переносились автоматически — добавлять их стоит после проверки и удаления демонстрационных примеров.

## Папки KubeJS (Forge 1.19.2)

- `server_scripts/` — рецепты и серверная игровая логика.
- `startup_scripts/` — регистрация контента, если она нужна и поддерживается модами.
- `client_scripts/` — клиентские изменения.

- `data/best_sborka/` — квесты (достижения) и награды, см. [docs/quests.md](../docs/quests.md).

## Проверка
После изменения скриптов запускай экземпляр и проверяй `logs/latest.log` локально. Логи в репозиторий не загружать.
