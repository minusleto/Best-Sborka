# Рецепты: сравнение IC2 и журнал изменений

Файл для людей и для других ИИ-ассистентов. Здесь фиксируем, чем рецепты IC2 Classic в сборке отличаются от IC2 Experimental 1.12.2, что мы уже изменили и что ещё планируем.

**Сборка:** Minecraft 1.19.2, Forge. Мод: IndustrialCraft 2 Classic `2.1.3.4` (IC2C). Эталон старых рецептов: IC2 Experimental `2.8.222-ex112` (1.12.2).
**Цель:** ваниль+ с IC2C и AE2 как основой, связать их, усложнить лейтгейм, добавить квесты.

## Как читать статусы

- `[x]` сделано (рецепт в сборке изменён, файл указан)
- `[ ]` не сделано / идея / только предстоит решить
- **усложнено**: дороже или длиннее, чем в оригинальном IC2C 1.19.2
- **упрощено**: дешевле, чем в оригинале (пока не используется)
- **как в оригинале**: сборка не трогает рецепт IC2C

Проверка в игре: все изменения ниже пока **не проверены в игре целиком**, кроме отмеченных `(проверено)`.

## Главный вывод сравнения

Рецепты IC2C 1.19.2 в основном совпадают с профилем **Classic** из 1.12.2, а не с **Experimental**. Experimental в целом дороже: железные пластины вместо слитков, стальные пластины в корпусах, энергетический кристалл через пыль и компрессор.

В IC2C 1.19.2 нет железных пластин, молота и металлоформовщика (правила профиля Classic: всё из слитков). Возвращаем систему пластин из IC2 Experimental 1.12.2.
- [x] Предмет `kubejs:iron_plate` («Железная пластина», теги `forge:plates`, `forge:plates/iron`), текстура из IC2 Experimental.
- [x] Предмет `kubejs:forge_hammer` («Кузнечный молот», 80 использований), текстура из IC2 Experimental. Значение прочности 80 выбрано нами, оригинальное в 1.12.2 не сверяли.
- [x] Рецепт молота как в 1.12.2: 5 железных слитков + 2 палки (`II_/ISS/II_`, оба зеркальных варианта).
- [x] Железная пластина в верстаке как в 1.12.2: железный слиток + молот (бесформенный), молот теряет 1 прочность.
- [x] Железная пластина в компрессоре: 1 железный слиток → 1 пластина (замена режиму «прокатка» металлоформовщика). IC2C и сам делает пластину продвинутого сплава в компрессоре.
- [x] Проверено в игре владельцем сборки: молот, пластины и текстуры работают.
- Файлы: `kubejs/startup_scripts/items.js`, `kubejs/server_scripts/ic2_energy_crystal.js`, `kubejs/data/ic2/ic2_recipes/compressor/iron_plate.json`, `kubejs/assets/kubejs/textures/item/iron_plate.png` и `forge_hammer.png`, `kubejs/assets/kubejs/lang/ru_ru.json`.

## Заметки для ИИ-ассистентов (что мы выяснили)

**Откуда берутся данные**
- Рецепты IC2 Experimental 1.12.2: внутри jar в `assets/ic2/config/*.ini` (профиль Experimental) и `ic2/profiles/classic/*.ini` (профиль Classic).
- Рецепты IC2C 1.19.2 прописаны в коде, а не в JSON внутри jar: класс `ic2/core/platform/registries/IC2Recipes.class`. Читать удобно после декомпиляции (Vineflower).
- Часть имён предметов в декомпилированном коде обфусцирована (`Items.f_42534_` это лазурит, `Items.f_42525_` светящаяся пыль).

**KubeJS и IC2C**
- Крафтовые рецепты IC2C видны для `event.remove({ output: '...' })` и `event.shaped(...)`, обычные ID предметов работают.
- Рецепты **машин** IC2C (компрессор и др.) лежат в датапаке: `kubejs/data/ic2/ic2_recipes/<машина>/<имя>.json`.
- Формат такого JSON строгий: у входа и выхода нужен `type` (`ic2:item` для входа, `ic2:simple` для выхода), у предметов в `outputs` тоже нужен `type` (`ic2:item`), а количество называется **`size`**, не `count`. Если ошибиться, IC2C молча пропускает рецепт, а в `logs/latest.log` пишет `Recipe [...] wasn't able to load`.
- Новые предметы регистрируются в `startup_scripts`, поэтому после правок нужен полный перезапуск игры (не `/reload`).

**Грабли, на которые мы уже наступали**
- PNG-текстуру нельзя копировать как текст: файл ломается (потом в игре фиолетово-чёрная клетка). Брать файл целиком.
- Перед коммитом проверять `git status`: один раз правки не попали в коммит, потому что их не добавили (`git add`).
- Файл `kubejs/assets/kubejs/items/*.json` для 1.19.2 не нужен (это формат Minecraft 1.21.4).
