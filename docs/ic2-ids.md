# Проверенные ID предметов и блоков IC2 Classic 2.1.3.4

Список снят с **декомпилированного JAR** `IC2Classic-1.19.2-2.1.3.4.jar` (Vineflower; классы `IC2Items`, `IC2Blocks` и конструкторы инструментов). Эти предметы и блоки существуют в игре под указанными именами. Блок получает предмет с тем же ID (`ic2:generator` — и блок, и предмет).

Список **неполный**: попали имена, заданные строкой в коде. Предметы, у которых имя берётся в другом месте, проверяйте отдельно по конструктору класса.

Примечания по именам, которые легко перепутать:
- лапотронный кристалл: `ic2:lapatron_crystal` (через «a», текстура при этом называется `lapotron_crystal`);
- стекловолоконный кабель: `ic2:glassfiber_cable_item`;
- кран для резинового дерева: `ic2:tree_tap`, электрический: `ic2:electric_tree_tap`;
- прибор ночного видения: `ic2:nightvision_goggles`;
- резиновое дерево: блок `ic2:rubber_wood`, саженец `ic2:rubber_sapling`, смола `ic2:sticky_resin`.
