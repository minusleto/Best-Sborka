# Квесты (FTB Quests)

Квестовая книга для тех, кто в техномодах не разбирается: у каждого квеста есть пояснение «что это, зачем, как». Файлы лежат в `config/ftbquests/quests/`:

- `data.snbt` — общие настройки;
- `chapter_groups.snbt` — группы глав (сейчас пусто);
- `chapters/*.snbt` — по одному файлу на главу.

**Мод:** FTB Quests `1902.5.10-build.497`. Ему нужен мод **Item Filters** (`itemfilters` от `1902.2.9-build.46`), его в сборке пока нет, без него игра не запустится.

## Правила, которые мы выбрали

- Награды только предметами, без опыта и команд.
- Задачи на предметы не забирают предметы (`default_consume_items: false`).
- Для ванильных предметов берутся готовые изделия (верстак, печь, кирка), а не «любое дерево»: так не нужны теги и фильтры.
- В описаниях нет символов `{`, `}` и одиночного `&`: FTB Library считает их разметкой. Допустимы цветовые коды `&6`, `&b`, `&c`, `&7`, `&r`.
- ID квестов, задач и наград: 16 шестнадцатеричных цифр, **первая цифра от 0 до 7**. ID с первой цифрой 8–F мод не может прочитать (`Long.parseLong`) и молча заменяет случайным, из-за чего зависимости теряются.
- Стрелки между квестами показывают рекомендуемый порядок, а не точный рецепт: реальные ингредиенты смотри в JEI.

## Что проверено, а что нет

- Формат файлов сверен с кодом JAR FTB Quests 1902.5.10 и FTB Library 1902.4.2.
- ID предметов IC2C сверены со строковыми константами реестров мода (`IC2Items`, `IC2Blocks`), ID остальных модов — со списками предметов в их файлах локализации, `bs_machines:metal_former` — с исходниками `mods-src/bs-machines`.
- **В игре квесты не запускались.** Если какой-то предмет не найден, в квесте он будет «отсутствующим предметом», а в `logs/latest.log` появится запись.

## Как править

Проще всего в игре: режим редактора книги квестов (нужны права оператора), затем скопировать изменённые файлы из `config/ftbquests/quests/` в репозиторий. Если правишь файлы вручную, соблюдай формат: без запятых между элементами, `x` и `y` с суффиксом `d`, количество в задачах с суффиксом `L`, ID по правилу выше.

## Старая система: квесты как достижения Minecraft

Квесты сделаны как **достижения Minecraft** (datapack в KubeJS): отдельная вкладка «Best-Sborka: путь инженера» в меню достижений (клавиша `L`). Дополнительные моды не нужны.

Файлы:
- `kubejs/data/best_sborka/advancements/` — квесты;
- `kubejs/data/best_sborka/loot_tables/rewards/` — награды (предметы), опыт задан прямо в квесте.

### Дерево квестов

**Кузница** (старт, подсказывает рецепты сборки)
- Железный век → Хватка кузнеца (молот) → Прокат (железная пластина)

**Техника IC2**
- Прокат → Алмазная пыль → Энергетическая пыль → **Энергокристалл**
- Прокат → Каркас машины → Передовые материалы → **Продвинутый корпус** (испытание)

**Сеть ME (AE2)**
- Кварц Certus → Заряженный кварц
- Кварц Certus → Кремниевое дело → Печатный станок → Мозги сети (3 процессора) → Сердце сети (контроллер)
- Мозги сети → Дисковый отсек → Килобайты места → **Автоматизация** (молекулярный сборщик, испытание)

**Исследование**
- В глубину! (Y ≤ -40) → Алмазная лихорадка → Дверь в ад → Древние обломки
- В глубину! → Тишина... подозрительная (Тёмные глубины)

**Финал**
- **Легенда Best-Sborka** — открывается, когда выполнены: энергокристалл, продвинутый корпус, молекулярный сборщик и Тёмные глубины.

### Награды
Награды помогают пройти ранний этап (редстоун, алмазы, пластины), но не заменяют добычу: числа небольшие. Все числа правятся в `loot_tables/rewards/*.json` и в поле `rewards.experience` каждого квеста.

### Как добавить квест
1. Скопируй похожий JSON из `advancements/`, поменяй `parent`, `icon`, текст и предмет в `criteria`.
2. Если нужна награда, создай одноимённый файл в `loot_tables/rewards/` и укажи его в `rewards.loot`.
3. Выполни `/reload` в игре и открой меню достижений.

### Проверка
Все ID предметов проверены: `ic2:*` и `kubejs:*` — по скриптам репозитория, `ae2:*` — по исходникам AE2 (ветка forge/1.19.2). Если в `logs/latest.log` появится ошибка про `best_sborka`, пришли её — поправим.
