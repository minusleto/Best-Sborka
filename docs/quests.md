# Квесты (FTB Quests)

Квестовая книга для тех, кто в техномодах не разбирается: у каждого квеста есть пояснение «что это, зачем, как». Файлы лежат в `config/ftbquests/quests/`:

- `data.snbt` — общие настройки;
- `chapter_groups.snbt` — группы глав (сейчас пусто);
- `chapters/*.snbt` — по одному файлу на главу.

**Мод:** FTB Quests `1902.5.10-build.497`. Ему нужен мод **Item Filters** (`itemfilters` от `1902.2.9-build.46`), по словам владельца он уже стоит в сборке (в наших исходниках `mods` его нет, лежит у владельца).

## Политика: квесты в последнюю очередь

Пока сборка меняется (новые машины, блоки, рецепты), квесты про наши моды и рецепты **не правим**: главы IC2, AE2, «Снаряжение», «Дополнения» и «Легенда» обновляем в самом конце, когда набор модов и рецептов будет готов. Исключение — глава «Ваниль»: она не зависит от наших правок и может развиваться сейчас. Типы заданий там разные: предмет, убийство мобов, биом, структура, ванильное достижение, измерение, глубина.

## Случайные награды и ремарки

У каждого квеста глав «Ваниль», «IC2: основы» и «IC2: энергия» (и у новых квестов Ванили) есть **дополнительная случайная награда**: одна вещь из таблицы нужной ступени. Прежние фиксированные награды сохранены.

| Таблица (`reward_tables/`) | Для чего |
|---|---|
| `vanilla_low`, `vanilla_mid`, `vanilla_high` | еда, факелы, железо → золото, лазурит, жемчуг → алмазы, блейз-стержни, золотые яблоки |
| `ic2_low`, `ic2_mid`, `ic2_high` | резина и пыль → схемы, бронза, батареи → продвинутые схемы, углеродные пластины, алмазная пыль |

Награда из таблицы — только предметы, как и требует правило ниже. Вес предмета (`weight`) задаёт шанс, `count` — количество. Чтобы убрать случайную награду у квеста, удали у него блок `type: "random"`.

В конце описания каждого такого квеста стоит серая **ремарка** (`&7...&r`): короткая шутка после объяснения «что, зачем, как». Новые квесты Ванили пишутся в том же стиле.

## Правила, которые мы выбрали

- Награды только предметами, без опыта и команд (случайные таблицы тоже содержат только предметы).
- Задачи на предметы не забирают предметы (`default_consume_items: false`).
- Для ванильных предметов берутся готовые изделия (верстак, печь, кирка), а не «любое дерево»: так не нужны теги и фильтры.
- В описаниях нет символов `{`, `}` и одиночного `&`: FTB Library считает их разметкой. Допустимы цветовые коды `&6`, `&b`, `&c`, `&7`, `&r`.
- ID квестов, задач и наград: 16 шестнадцатеричных цифр, **первая цифра от 0 до 7**. ID с первой цифрой 8–F мод не может прочитать (`Long.parseLong`) и молча заменяет случайным, из-за чего зависимости теряются.
- Стрелки между квестами показывают рекомендуемый порядок, а не точный рецепт: реальные ингредиенты смотри в JEI.

## Что проверено, а что нет

- Формат файлов сверен с кодом JAR FTB Quests 1902.5.10 и FTB Library 1902.4.2.
- ID предметов IC2C сверены со строковыми константами реестров мода (`IC2Items`, `IC2Blocks`); список проверенных ID лежит в [ic2-ids.md](ic2-ids.md), ID остальных модов — со списками предметов в их файлах локализации, `bs_machines:metal_former` — с исходниками `mods-src/bs-machines`.
- **В игре квесты не запускались.** Если какой-то предмет не найден, в квесте он будет «отсутствующим предметом», а в `logs/latest.log` появится запись.

## Как править

Проще всего в игре: режим редактора книги квестов (нужны права оператора), затем скопировать изменённые файлы из `config/ftbquests/quests/` в репозиторий. Если правишь файлы вручную, соблюдай формат: без запятых между элементами, `x` и `y` с суффиксом `d`, количество в задачах с суффиксом `L`, ID по правилу выше.
