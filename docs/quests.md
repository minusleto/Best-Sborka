# Квесты Best-Sborka (FTB Quests)

Квесты лежат в `config/ftbquests/quests/` и подхватываются модом **FTB Quests** (Minecraft 1.19.2, Forge).

## Что нужно для работы
1. В `mods/` должен лежать `ftb-quests-forge-1902.x.jar` (зависимости FTB Library, FTB Teams и Architectury уже стоят).
2. Папка `config/ftbquests/` копируется в экземпляр игры (на сервере — в папку сервера).
3. Открыть книгу: кнопка FTB Quests в боковой панели инвентаря или `/ftbquests open_book`. Книгу-предмет (`ftbquests:book`) даёт приветственный квест.

## Главы

| Глава | Файл | Квестов | О чём |
|---|---|---|---|
| Ванила | `chapters/vanilla.snbt` | 35 | выживание: дерево → печь → железо → алмазы → Незер; QoL-советы по модам сборки |
| Техника IC2 | `chapters/ic2.snbt` | 60 | металлы и резина, генератор, дробилка, компрессор, накопители, энергокристалл, корпуса, массфаб, реактор |
| Сеть ME | `chapters/ae2.snbt` | 9 | кварц Certus → процессоры → контроллер, привод, ячейка, сборщик |
| Легенда | `chapters/finale.snbt` | 1 | открывается после энергокристалла, продвинутого корпуса, молекулярного сборщика и Тёмных глубин |

Зависимости между главами работают: IC2 начинается после «Железного века» из Ванилы, AE2 — после спуска в глубину.

## Награды: рандомные таблицы
Почти каждый квест даёт **случайную награду** из таблицы по ступеням (`reward_tables/`, одна награда за раз, у предметов есть веса):

| Таблица | Содержимое |
|---|---|
| `vanilla_low` / `vanilla_mid` / `vanilla_high` | еда, факелы, железо → золото, лазурит, жемчуг → алмазы, блейз-стержни, золотые яблоки |
| `ic2_low` / `ic2_mid` / `ic2_high` | резина и пыль → схемы, бронза, батареи → продвинутые схемы, углеродные пластины, алмазная пыль |
| `ae2_low` / `ae2_high` | кварц, кремний, флюикс → заряженный кварц, процессор |

Помимо случайной награды, у вех есть гарантированные (опыт, алмазы, пластины). Награды забираются кнопкой в квесте (`default_autoclaim_rewards: disabled`). Количество и веса правятся в `reward_tables/*.snbt` (поля `count` и `weight`).

## QoL
- Приветственный квест выдаёт стартовый набор и **книгу квестов**.
- В Ванили 6 советов по модам сборки: JEI, Jade и TOP, Xaero, Crafting Tweaks, Curios, Fast Leaf Decay. Награда за каждый случайная.
- В описании каждого квеста: зачем нужна вещь и короткая ремарка.
- Интеграция с JEI включена (`default_quest_disable_jei: false`).
- Задания «предмет» только **проверяют наличие** (`default_consume_items: false`), ничего не забирают.
- Режим прогрессии `flexible`: можно идти по разным веткам.

## Правила ID (важно при ручной правке)
- ID объектов (глав, квестов, заданий, наград, таблиц) — **16 шестнадцатеричных цифр**, и значение должно быть **меньше `8000000000000000`**: мод читает его как знаковое 64-битное число. Если первая цифра 8–F, мод молча подменяет ID на случайный, и зависимости на этот квест пропадают (квест будет без линии к предыдущему).
- `table_id` у награды `random` — десятичное число с суффиксом `L`, равное ID таблицы.
- При копировании квеста меняй все `id` внутри него.
- Редактор в игре: `/ftbquests editing_mode`. После ручной правки на сервере: `/ftbquests reload`.

## ID предметов
Все ID сверены автоматически: ванильные по реестру 1.19.2, `ic2:*` по декомпилированному JAR IC2 Classic 2.1.3.4 (см. [ic2-ids.md](ic2-ids.md)), `ae2:*` по исходникам AE2 (forge/1.19.2), `kubejs:*` по `startup_scripts/items.js`, `bs_machines:metal_former` по `mods-src/`.

Зависимости в IC2 отражают **рекомендуемый порядок**, а не точные рецепты. Описания машин общие: проверяй детали в JEI.

## Не проверено в игре
Расстановка квестов, награды и работа заданий (особенно `location` для глубины и `biome` для Тёмных глубин) проверены по исходникам FTB Quests и разбором файлов, но не запускались в клиенте.
